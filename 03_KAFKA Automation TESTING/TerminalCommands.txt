These commands match this machine: Windows 11, PowerShell, no Docker or WSL, Java 26 (`JAVA_HOME` already set), Node 24, and `curl.exe` and `tar.exe` built in. They run Kafka and Node-RED directly on Windows, without Docker. I couldn't run them end to end myself, because starting Kafka was blocked earlier in this session.

## 1. One-time setup: download and configure Kafka

```powershell
cd C:\
curl.exe -L -o kafka.tgz https://archive.apache.org/dist/kafka/3.9.1/kafka_2.13-3.9.1.tgz
tar -xzf kafka.tgz
Rename-Item C:\kafka_2.13-3.9.1 C:\kafka
Remove-Item C:\kafka.tgz
cd C:\kafka

# Make a config matching docker-compose.yml: data in C:\kafka\data, no topic auto-create, no rebalance delay
(Get-Content config\kraft\server.properties) -replace '^log.dirs=.*','log.dirs=C:/kafka/data' | Set-Content config\kraft\qa.properties
Add-Content config\kraft\qa.properties "auto.create.topics.enable=false`ngroup.initial.rebalance.delay.ms=0"

# Format the storage (only needed once)
$id = .\bin\windows\kafka-storage.bat random-uuid | Select-Object -Last 1
.\bin\windows\kafka-storage.bat format -t $id -c config\kraft\qa.properties
```

Use `C:\kafka` and not a folder under your user profile. Kafka's Windows scripts build one long classpath, and a longer install path pushes it close to the Windows command-line length limit.

## 2. Window 1: start Kafka (leave it open)

```powershell
cd C:\kafka
$env:KAFKA_HEAP_OPTS = "-Xmx1G -Xms1G"     # also skips the script's wmic call; wmic is gone on newer Windows 11
.\bin\windows\kafka-server-start.bat config\kraft\qa.properties
```
Wait until the window shows `Kafka Server started`.

## 3. Window 2: create the topics (one time)

```powershell
cd C:\kafka
foreach ($t in 'qa.orders.v1','qa.orders.processed.v1','qa.orders.dlq.v1') {
  .\bin\windows\kafka-topics.bat --bootstrap-server localhost:9092 --create --if-not-exists --topic $t --partitions 1 --replication-factor 1
}
.\bin\windows\kafka-topics.bat --bootstrap-server localhost:9092 --list
```

## 4. Window 3: start Node-RED (leave it open)

```powershell
$P = "C:\Users\a_hos\Downloads\00_Assignment V2\00_Assignment\03_KAFKA Automation TESTING\PROJECT FILES"
```

Wait until it shows `Started flows`. The editor is at http://localhost:1880.

## Stop or reset

- **Stop:** press Ctrl+C in the Kafka and Node-RED windows.
- **Reset Kafka:** Kafka sometimes crashes on Windows with `AccessDeniedException` on its log files, which is a known Windows problem. To start fresh, run `Remove-Item -Recurse -Force C:\kafka\data`, then repeat the format command at the end of step 1 and step 3.
- **If Kafka won't start at all:** it may be Java 26, which Kafka 3.9.1 doesn't officially support. Installing Java 21 (`winget install -e --id Microsoft.OpenJDK.21`) and setting `$env:JAVA_HOME` to it before step 2 should fix that.
